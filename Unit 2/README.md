# Unit 2: Essential Data Structures

As we have seen in previous lessons, efficient algorithms depend on efficient/effect arrangements of data. For example, both arrays and linked lists (two of the most elementary data structures) could be leveraged in conjunction with clever algorithms to efficiently implement the abstract data types `Stack`, `Queue`, and `List`. In other words, the way we store the data in memory affects the efficiency of the algorithm operating on that data.

In general, we will consider the term **data structure** to encompass both the format/arrangement of data _and_ the functions for accessing and modifying it. Subsequently, we will deploy these data structures to efficiently implement a variety of ADTs. Perhaps surprisingly (or not), it turns out we can use the same data structure to implement apparently very different APIs.
